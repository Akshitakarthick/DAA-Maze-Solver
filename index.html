What is Backtracking?

Backtracking is a systematic algorithm that incrementally builds candidates to solutions, abandoning ("pruning") a candidate as soon as it's determined it cannot lead to a valid solution.

function solve():
    if solution_found:
        return True

    for each choice:
        if is_valid(choice):
            make_choice()
            if solve():
                return True
            undo_choice()   ← BACKTRACK

    return False

Time Complexity

Sudoku
O(9m)
m = empty cells. With MRV heuristic, often much better in practice.
N-Queens
O(N!)
N rows × N choices each. Pruning reduces to ~O(N!/some_factor).

Pruning in Action

Sudoku Constraints
  • ✗ Number already in same row
  • ✗ Number already in same column
  • ✗ Number already in 3×3 subgrid
  • ✓ MRV: Fill most-constrained cell first
N-Queens Constraints
  • ✗ Queen in same column
  • ✗ Queen on upper-left diagonal
  • ✗ Queen on upper-right diagonal
  • ✓ Each row gets exactly one queen
